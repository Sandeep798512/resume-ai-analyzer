ResumeAI V2 Architecture & Viva Reference

A complete technical reference for B.Tech Computer Science (AI) Viva voce examinations and portfolio evaluations.

1. Hybrid Architecture Overview

ResumeAI V2 combines statistical TF-IDF text mining with deep semantic transformer embeddings, structured database persistence, and production security middleware.

[User Upload / Resume Builder] → [PDF Parser & Security Header Check]
                                                        ↓
[TF-IDF Engine 25%] + [Sentence-Transformers 35%] + [Skill Match 30%] + [Keywords 10%]
                                                        ↓
[Hybrid Match Score %] → [AI Interview Prep] → [Targeted Optimization] → [ReportLab PDF Export]

2. Hybrid AI Job Match Formula

To eliminate single-algorithm bias, candidate resumes and job postings are evaluated using four mathematical components:

Component Weight Technical Implementation
Semantic Vector Similarity35%Cosine similarity of 384-dimensional dense vectors using sentence-transformers (all-MiniLM-L6-v2)
Skill Match Rate30%Categorized skill set overlap ratio across 11 skill categories
TF-IDF Text Match25%Unigram/Bigram sparse matrix cosine similarity via scikit-learn TfidfVectorizer
Keyword Coverage10%Audit of top 15 extracted job posting terms present in resume text

3. Production Security & Infrastructure

  • CSRF Protection: All state-changing POST forms are protected via Flask-WTF (CSRFProtect).
  • Rate Limiting: Endpoint rate limits enforced via Flask-Limiter to prevent brute-force attacks and server overload.
  • PDF Header Security: Uploads are validated for %PDF- magic byte headers to prevent malicious file uploads.
  • Authorization Security: Strict owner verification ensures users can only access their own resumes, analyses, and versions.
  • Cloud & Docker Ready: Includes Dockerfile, docker-compose.yml, Gunicorn WSGI server, and dynamic PostgreSQL database support.

4. Key Viva Questions & Answers

Q1: Why combine TF-IDF with Sentence Transformers in a Hybrid approach?

Answer: TF-IDF excels at exact technical keyword matching (e.g. c++, sqlite), whereas Sentence Transformers capture deep semantic context (e.g. recognizing that "built microservices" aligns semantically with "backend REST architecture"). Combining both yields superior matching accuracy.

Q2: How does the PDF Exporter work without JavaScript?

Answer: It uses Python's ReportLab library to construct vector PDF canvas elements and paragraph styles directly on the server, generating high-quality selectable PDF bytes streamable to the client browser.
